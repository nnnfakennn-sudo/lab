# CP Exam Prep

C programs for competitive programming lab exam.

| File | Topic |
|---|---|
| malloc.c | malloc() usage |
| calloc.c | calloc() usage |
| realloc.c | realloc() usage |
| menudriven.c | Array: insert/delete/search/display/exit |
| bt_array.c | Binary Tree using array (in/pre/post order) |
| bt_ll.c | Binary Tree using linked list (in/pre/post order) |
| trie_create.c | Trie node creation |
| trie_insert.c | Trie insert + search |
| fibonacci.c | Fibonacci series |
| knapsack.c | 0/1 Knapsack (DP) |
| bfs.c | Breadth First Search |
| dfs.c | Depth First Search |

## Build & Run
```bash
gcc filename.c -o out
./out
```
